# 🎨 Spirograph

A simple **Spirograph drawing project built with Python's Turtle graphics**.
The program creates colorful, geometric patterns by repeatedly drawing circles while changing the turtle's heading.

## 🚀 Features

* Generates colorful spirograph patterns
* Uses Python's built-in `turtle` module
* Uses random colors for each circle
* Demonstrates loops, functions, and turtle graphics
* Simple and beginner-friendly Python project

## 🛠️ Technologies Used

* **Python**
* **Turtle Graphics**
* **Random Module**

### 1. Clone the repository

```bash
git clone <your-repository-link>
```


### 3. Run the Python file

```bash
python3 main.py
```

A Turtle graphics window will open and draw the spirograph.
